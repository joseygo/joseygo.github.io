【分析挖掘】交易项目常用指标及计算方法

1. 前言

从事交易类项目有段时日了，这边整理一下思路，默一下常用的核心指标 / 数据吧；
从物理视角来说，本该从APP的下载开始；
但，笔者坚持：用户的画像，决定核心业务涉及指标；所以，烦请读者老爷们尊重这个顺序；
重中之重数据，已加粗斜体处理；

============================================================================================

2. 指标 / 数据 适用声明

手持端类型：手机APP（未包含PC、小程序）；
供应方式：B2B2C入驻；
主营品类：全品类；
商品性质: 实物类；
履约方式：快递 / 同城运输；

============================================================================================

3. 关键指标/数据陈列

以下数据中，很大一部分可通过SDK厂商提供的全埋点服务直接可视化，笔者将用【全埋点】一笔带过；
某些指标拥有多种计算方式，笔者仅以较常见的计算方式进行说明；

3.1 用户类

3.1.1 基础信息

  • 注册时间
    获取 / 计算方法：由于国内互联网产品注册概念的淡化，一般用户的首次登录时间，视为注册时间；
  • 性别
    获取 / 计算方法：由于大部分产品，都用不到用户的性别，所以大多通过微信授权给与信息；
  • 出生年份
    获取 / 计算方法：a、实名认证的身份证号截取；b、引导用户填报数据；
  • 生日
    获取 / 计算方法：a、实名认证的身份证号截取；b、引导用户填报数据；
  • 常驻城市
    获取 / 计算方法：a、收货地址分析；b、GPS实时定位；c、引导填报；（几个维度，记录的结果可能不一样，需明确使用场景）；
  • 系统
    获取 / 计算方法：全埋点统计；
  • 手机品牌
    获取 / 计算方法：全埋点统计；
  • 手机型号
    获取 / 计算方法：全埋点统计；
  • 设备号
    获取 / 计算方法：全埋点统计；

3. 1.2 行为信息

  • 启动次数
    获取 / 计算方法：全埋点统计；

  • 登录间隔时间
    获取 / 计算方法：全埋点统计；

  • 浏览页面量
    获取 / 计算方法：全埋点统计；

  • 浏览时长
    获取 / 计算方法：全埋点统计；

  • 转发量
    获取 / 计算方法：全埋点统计；

  • 回流率
    获取 / 计算方法：全埋点统计；

  • 收藏量
    获取 / 计算方法：前端记录收藏按钮事件；

  • 加购量
    获取 / 计算方法：前端记录加购按钮事件；

  • 购车提订单量
    获取 / 计算方法：前端记录购物提交订单事件；

  • 商品直提单量
    获取 / 计算方法：前端记录商品详情页提交订单事件；

  • 客单价
    获取 / 计算方法：订单总金额/订单总笔数（平均客单价算法）；

  • 其实客单价的中位数，也很有参考价值；

  • 联系客服量
    获取 / 计算方法：前端记录联系客服点击事件，或由客服系统服务商提供；

  • 优惠券使用率
    获取 / 计算方法：被使用的优惠券量 / 发放量；

  • 申请退货量：
    获取 / 计算方法：退货量 / 订单量；

3.2 商家类

3.2.1 基础信息

  • 入驻时间
    获取 / 计算方法：商家入驻申请被审批通过的时间；
  • 主营品类
    获取 / 计算方法：一般会要求入驻商提供信息；
  • 上架商品量
    获取 / 计算方法：数据库可统计得出；
  • 货仓地点
    获取 / 计算方法：一般由商家填写，经常会有一户多仓的情况；
  • 合作快递
    获取 / 计算方法：可将快递公司数据化供选，便于统计实际发货使用情况；
  • 发货时效
    获取 / 计算方法：发货时间 - 订单支付时间；
  • 服务质量
    获取 / 计算方法：多个主维度取平均值或甲醛算法均可；

3.2.2 经营信息

  • 客服响应时长
    获取 / 计算方法：客服系统服务商可提供；
  • 进店用户量
    获取 / 计算方法：进入店铺主页量+查看商品量（用户id去重）；
  • 浏览商品量
    获取 / 计算方法：前端记录用户查看商品的id，统计用户浏览商品的数量（商品id去重）；
  • 加购量
    获取 / 计算方法：查询加入购物车的商品量（不去重）；
  • 收藏量
    获取 / 计算方法：查询收藏的商品量（不去重）；
  • 订单量
    获取 / 计算方法：查询有效订单量；
  • 退货量
    获取 / 计算方法：退货的订单量；
  • 发货时效
    获取 / 计算方法：用户下单时间~发货时间的时间差；
  • 客单价
    获取 / 计算方法：主要有平均数和中位数2种；

3.3 平台经营类

  • 下载量
    获取 / 计算方法：可通过应用市场查询获取；
  • 注册量
    获取 / 计算方法：数据库统计较准确；
  • 跳出率
    获取 / 计算方法：全埋点统计；
  • DAU
    获取 / 计算方法：全埋点统计；
  • MAU
    获取 / 计算方法：全埋点统计；
  • 次日留存率
    获取 / 计算方法：全埋点统计；
  • 7日留存率
    获取 / 计算方法：全埋点统计；
  • 30日留存率
    获取 / 计算方法：全埋点统计；
  • 月活跃用户
    获取 / 计算方法：连续4周，每周至少启动过一次APP的活跃用户；
  • GMV
    获取 / 计算方法：创建订单涉及的总金额；
  • 转发率
    获取 / 计算方法：转发量 / 曝光PV；
  • 订单转化率
    获取 / 计算方法：日订单 / DAU；
  • 下单峰期
    获取 / 计算方法：统计订单创建时间可知；
  • 支付转化率
    获取 / 计算方法：有效订单量 / 创建订单量；
  • 复购率
    获取 / 计算方法：2次以上有效订单的用户量 / 1次及以上有效订单的用户量；
  • 连带率
  • LTV
    获取 / 计算方法：LT（生命周期（日））* ARPU（每用户平均收入）；

  • 退货率
    获取 / 计算方法：退货量/订单量；
